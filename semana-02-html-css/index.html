sobre

Comecei a programar na pandemia, fazendo mods e plugins de Minecraft para o servidor que eu mantinha com os amigos. Com o tempo, resolver os problemas ficou mais divertido que jogar.

Hoje curso Engenharia de Computação na UNIFEI e sou trainee de Desktop na Asimov Jr., onde fui membro destaque em outubro. Gosto de tratar o que faço como se fosse meu: se é para entregar, é para entregar direito.

Quando não estou programando, provavelmente estou com a minha namorada, cozinhando, vendo jogo do Bulls ou com música no fone.

habilidades

Back-end

Java, Spring Boot, NestJS, PostgreSQL

Java é a linguagem em que mais me sinto em casa. Com Spring Boot e NestJS monto APIs com autenticação, banco de dados e documentação.

Front-end

TypeScript, Angular, React, Tailwind

Uso TypeScript sempre que dá. Angular é o foco da capacitação na Asimov, e React foi o que usei no front do Alphaville WMS.

Base

C++, C, Python

C++ é minha arma para algoritmos e programação competitiva. C me ensinou o que acontece por baixo dos panos.

Ferramentas

Git, GitHub Actions, Docker, Linux

Versiono com Git, subo ambientes com Docker e faço deploy em servidor Ubuntu via SSH. No dia a dia, programo no Arch Linux.

Idiomas

Português e inglês avançado

Também arrisco um espanhol e um francês básicos.

Também passei por Haskell, Assembly, VHDL, FPGA, MATLAB e microcontroladores PIC nas disciplinas da faculdade.
